# 安装与使用

## 前置条件

1. Windows 11 22H2 或更新版本。
2. VK03 副屏已通过内部 USB 线连接，设备管理器中出现 `MS USB Display`（`VID_345F&PID_9132` 的 MI_03）。
   - 该接口需要 **libusb-win32（libusb0）** 驱动。厂商程序（Myth.Cool 等）安装时通常会一并安装。
   - 首次使用若设备管理器显示未知设备或黄色感叹号，请先安装厂商程序，再回到本程序。
3. 退出正在使用副屏的厂商程序，否则两边会争用同一个接口。

不需要管理员权限：副屏视频接口由 libusb0 驱动向普通用户开放。

## 安装

1. 将 `dist/VK03Panel/` 整个目录解压到固定位置，例如 `C:\Tools\VK03Panel`。
2. 双击 `VK03Panel.exe`，设置窗口打开，副屏应显示与预览一致的面板。
3. 在「外观」选择副屏主题：`Windows 11`（默认）或 `macOS`；可切换深浅色与强调色来源。
4. 在「副屏」确认连接状态与安装方向。实测方向为 **90°**；其他方向可切换但属实验性。
5. 需要开机自启时，在「启动」页打开「开机自动启动」。程序会写入
   `HKCU\Software\Microsoft\Windows\CurrentVersion\Run\VK03Panel`，参数为 `--background`。

关闭设置窗口只会隐藏到托盘，程序继续刷新副屏；从托盘菜单选择「退出」才会停止并（可选）关闭副屏。

## 触屏

触屏控制器 `VID_374A&PID_A401` 由 HID 与 libusb0 两种后端自动探测。若设备管理器显示
「问题代码 10」（`CM_PROB_FAILED_START`），说明 Windows 未能启动该设备，面板会显示「等待触屏」，
触控操作可用「副屏」页的预览代替（鼠标点击预览即可模拟）。

处理建议：

1. 在「数据」页点击「修复触屏（管理员）」：程序会先重启设备，若仍失败则移除并重新扫描，
   让 Windows 重新安装 HID 驱动（需要 UAC 授权）。
2. 拔插副屏的 USB 线或重启电脑，让触屏控制器重新枚举。
3. 确认没有其他程序独占该设备。
4. 若仍然无效，说明 Windows HID 驱动无法解析该触屏（问题代码 10 会在重启设备后重现）。
   可以用 [Zadig](https://zadig.akeo.ie/) 将触屏切换为 USB 直读：
   - 以管理员运行 Zadig → Options → List All Devices；
   - 在设备下拉框选择 USB 输入设备 (374a:a401) / Interface 0；
   - 驱动目标选择 **libusb-win32**，点击 “Replace Driver”；
   - 回到本程序「数据」页点击「重新检测」，触屏会以“USB 直读”后端连接。
   切换驱动会改变该设备在 Windows 中的绑定方式；如需恢复，可在 Zadig 中重新安装原来的 HID 驱动，
   或在设备管理器中卸载设备后重新扫描。
5. 也可以把触屏的内部 USB 线换到主板上另一个 USB 2.0 接口，或重启电脑后重试（部分集线器
   供电/复位异常会导致同样的错误）。

## CPU 温度

CPU 温度直接来自 **AMD Ryzen Master SDK**（Ryzen Master 驱动随 AMD 显卡/芯片组驱动安装）。
该驱动只允许管理员访问：

1. 在「数据」页点击「以管理员身份重启」，在 UAC 中允许；
2. 或在「启动」页开启「开机自动启动」——以管理员运行时程序会自动注册最高权限计划任务，
   以后登录即自动以管理员启动，不再弹 UAC；
3. 如果暂时不想提权，可安装 [HWiNFO](https://www.hwinfo.com/) 作为回退来源：

1. 在 Sensors 窗口中保持运行；
2. 在 Settings → Safety 中勾选 **Shared Memory Support**；
3. 回到本程序「数据」页点击「重新检测」。

程序会优先读取 HWiNFO 共享内存，其次尝试 LibreHardwareMonitor 的 WMI 提供程序。
两者都不可用时面板显示 `—`（不会伪造读数）。

## 卸载

1. 在「启动」页关闭「开机自动启动」；
2. 从托盘菜单退出程序；
3. 删除安装目录；
4. 可选：删除 `%APPDATA%\VK03Panel`（配置）与 `%LOCALAPPDATA%\VK03Panel`（预览、日志、诊断）。

本程序不安装服务、驱动或开机计划任务。

## 常见问题

| 现象 | 处理 |
|---|---|
| 设置页显示「等待副屏」 | 确认设备管理器中的 `MS USB Display` 正常；关闭厂商程序后点击「重新连接」 |
| 提示「无法占用副屏视频接口」 | 有其它程序占用接口，退出后重试 |
| 提示「芯片签名与 MS912C 不符」 | 面板型号不匹配，程序拒绝初始化以避免误刷 |
| 面板有画面但方向不对 | 在「副屏」页切换方向；90° 为实机验证方向 |
| CPU 温度显示 `—` | 按上文接入 HWiNFO 共享内存 |
| 触屏无反应 | 见「触屏」一节 |
