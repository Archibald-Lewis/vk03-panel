# 副屏主题

六款主题使用相同的 960×360 设计画布、监控数据和触控状态机。在设置窗口“外观”页切换后立即生效，并保存为 `ThemeId`。

| ID | 主题 | 布局 |
|---|---|---|
| `win11` | Windows 11 | 左侧时钟与锁屏，顶部任务管理器式 CPU / 内存 / GPU 网格曲线，底部媒体与音量 |
| `mac` | macOS | 控制中心式半透明模块：时钟、媒体、硬件概览、音量和锁屏 |
| `nebula` | 星环 | 深空背景、单色 CPU 环形仪表、内存与 GPU 趋势、近期峰值、底部统一媒体栏 |
| `immersive` | 沉浸播放 | 大封面、缓存的模糊封面背景、歌曲 / 歌手 / 专辑、播放控制、进度跳转和音量 |
| `sketch` | 手绘卡通 | 原创耳机猫咪、蜡笔纸张、手画 CPU / 内存 / GPU 仪表与底部媒体栏 |
| `anime` | 二次元 | 原创耳机角色、夜景、左侧封面与音乐控制、底部三项硬件概览 |

## Windows 11

- 中性灰背景，Segoe UI Variable 文字与系统 Segoe Fluent Icons。
- CPU / 内存 / GPU 使用独立的网格曲线和实时数值。
- 采用 Windows 系统强调色；深色时适当提亮。
- 音量滑条替代独立的加减按钮。

## macOS

- 采用中性半透明表面、圆角模块、细边线和轻微阴影，背景色透过模块形成层次。
- 时钟和媒体位于左侧；三个硬件模块显示主要数值与近期采样趋势。
- 音量使用胶囊滑条，并保留静音和加减按钮；播放按钮采用黑白填充，锁屏需要持续按住。
- 播放、音量和硬件图标使用项目内的矢量几何，不打包 Apple 图标字体。
- 字体优先使用已安装的 Helvetica Neue，未安装时回退到 Arial 与系统中文字库。Windows 版不附带 Apple 字体。
- 半透明效果由副屏位图渲染器绘制，不会捕获桌面，也不依赖 macOS 的实时模糊接口。

## 触控与渲染

主题在 `Bounds` 和 `HitTest` 中定义自己的热区；滑条位置通过 `SliderLeft` 与 `SliderWidth` 交给触控控制器。
实际画面与命中区共用设计坐标，方向转换由公共渲染和触控代码处理。

所有可见按钮的热区至少为 48×48 像素；六款主题都有热区不重叠、边缘命中和滑条端点测试。
只有 macOS 主题保留独立的 `Quieter` / `Louder` 按钮，其余主题用滑条调节音量。
沉浸播放增加 `Seek` 热区；手指松开时发出一次跳转请求，播放器不支持跳转时只显示进度。
点按 Windows 11 / macOS 的时钟，或星环的主题按钮，可依次循环切换主题并保存选择。沉浸播放、手绘卡通和二次元不提供主题切换热区，需通过设置“外观”页或托盘菜单切换。

## 星环与沉浸播放

星环的环形刻度表示真实 CPU 利用率，内存与 GPU 提供近期趋势。“近期峰值”取最近最多 40 个有效采样点，与正常采样频率一致；重绘和锁屏动画不会额外推进历史。

沉浸播放读取当前 Windows 媒体会话的实际封面、歌曲、歌手、专辑与时间轴。没有封面时使用静态唱片图形；不绘制伪造的实时音频频谱。背景模糊只在封面更换时计算并缓存。
沉浸播放使用中性色播放控件与柔化的封面背景，不使用金色描边或竖向分隔线。曲名最多显示两行，歌手与专辑分级呈现；音量数值仅在调节或静音操作时显示。播放器没有时间轴时不显示空进度条。
六款主题都支持深色和浅色。

## GPT Image 素材与插画主题

星环、手绘卡通和二次元的背景插画由内置 GPT Image 工具生成。生产素材与完整提示词位于 `assets/themes/` 和 `assets/themes/PROMPTS.md`。生成的图片不含按钮、文字、曲线或假数据；所有功能与实时数值仍由 WPF 绘制。

手绘卡通使用原创耳机猫咪与确定性的手画曲线边框；每次重绘不会随机抖动。二次元使用原创成年耳机角色，没有引入已有作品角色。两款新主题保留时钟、CPU / 内存 / GPU、媒体控制、音量、静音与按住锁屏。

素材作为程序集资源随应用发布，不需要联网或读取生成工具的缓存目录。首次使用时解码至 960×360，将像素复制到无解码器依赖的冻结位图后缓存，避免设置预览与副屏渲染线程间的图片访问异常。主题切换、媒体更新和按住锁屏不重复加载图片，也不改变指标采样频率。

```powershell
$cli = 'src\VK03Panel.Cli\bin\Release\net9.0-windows10.0.19041.0\VK03Panel.Cli.exe'
& $cli --demo assets\demo-mac-dark.png --theme mac --dark
& $cli --demo assets\demo-mac-light.png --theme mac --light
```

演示图使用合成数据；实时画面中缺失的传感器读数显示为 `—`。

## 空闲播放目标

“播放”设置页中的网易云目标只保存数字歌单 ID，原分享链接的额外参数不会保留。播放键先尝试控制已有媒体会话；只有无会话且启用空闲目标时才启动网易云。已登录状态及音乐权限由网易云客户端处理，应用不读取登录令牌。
